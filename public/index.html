    Terms & Conditions

    1. Shared editing. Anyone with the workspace link can view and edit the current code until the owner turns on the editing lock. Share links only with people you trust.

    2. Owner editing lock. The owner can lock editing. Other visitors can still read and copy code, but the server rejects their edit attempts. This is an editing permission lock, not encryption of the code contents.

    3. Saved workspaces. Workspace code is stored in a database so it is still there after the server restarts. Changes made by anyone with edit access are saved too. CodeRelay keeps only the latest version, not an edit history.

    4. No secrets. Do not paste passwords, API keys, access tokens, private keys, personal information, or confidential code into a shared workspace.

    5. Availability. The service is provided as-is and may be unavailable from time to time. A QR code is only a link to the workspace.

    6. Responsible use. Use this service only for lawful collaboration. These terms are a draft, not legal advice.

    What should your team call you?

    Enter your name once. You get a number, and both stay with this browser. They can't be changed later.

    Delete this workspace?

    The workspace link stops working for everyone, and the saved code and history are permanently removed. A copy of the text stays in your own editor.
