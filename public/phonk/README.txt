PHONK LIST
1. Put your .mp3 files in this folder (public/phonk/).
2. Write each phonk's name in phonks.json, in the order you want it shown.
3. The name must match the file name exactly (ignoring the .mp3), e.g.
      phonks.json:  ["Night Drive", "Drift King"]
      files:        Night Drive.mp3   Drift King.mp3
Names are case-sensitive on the server (Linux/Render). Everyone can play them.
